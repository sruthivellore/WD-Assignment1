## WD-Assignment1 – Responsive Resume Website

A simple, responsive resume website built with HTML and CSS as part of a web development class assignment.  
**Live Demo:** [https://sruthivellore.github.io/WD-Assignment1/](https://sruthivellore.github.io/WD-Assignment1/)

---

## Overview

This project is a personal resume website, created using only HTML and CSS. It presents education, work experience, skills, projects, and achievements in a clean, accessible format suitable for both desktop and mobile users. The assignment demonstrates the application of core web development principles, especially responsive design.

---

## Features

- **Single-page resume:** All information is presented on one HTML page.
- **Fully responsive:** Layout adapts smoothly to both mobile and desktop screens for optimal readability and navigation.
- **Modern, user-friendly design:** Uses clear headings, icons, and sections for easy scanning.
- **No JavaScript required:** Fast loading and simple maintenance.
- **Accessible:** Uses semantic HTML for better accessibility.

---

## User Experience

- **Mobile-Friendly:** The site layout and font sizes adjust for smaller screens, ensuring readability and easy navigation on smartphones and tablets.
- **Desktop Optimized:** On larger screens, content is spaced for comfortable reading and efficient use of space.
- **Consistent Content:** All sections are available on every device-no missing features or information.
- **Visual Highlights:** Use of icons (emojis) and section headers makes the resume engaging and easy to follow.

## Technologies Used

- **HTML5:** For semantic structure and content.
- **CSS3:** For layout, responsive design (using media queries), and styling.
- **No frameworks or JavaScript**-just pure HTML and CSS.
